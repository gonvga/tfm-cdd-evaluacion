# Progresión competencial

La aplicación organiza la evaluación en cuatro niveles:

```text
A1 → A2 → B1 → B2
```

## A1

Reconocimiento inicial de criterios, conceptos básicos y acciones guiadas.

## A2

Aplicación guiada de criterios en contextos educativos sencillos.

## B1

Uso autónomo de criterios para adaptar, organizar o seleccionar contenidos digitales.

## B2

Análisis crítico, integración de criterios avanzados y optimización de recursos o repositorios.

## Justificación

La progresión secuencial permite respetar el carácter acumulativo del desarrollo competencial. El usuario debe demostrar primero las capacidades básicas antes de avanzar a tareas más complejas.
