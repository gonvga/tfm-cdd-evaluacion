# Enfoque pedagógico

La aplicación se basa en un modelo de evaluación orientado al desempeño.

A diferencia de los cuestionarios de autopercepción, la herramienta plantea tareas prácticas que obligan al usuario a realizar acciones observables:

- Seleccionar recursos.
- Clasificar materiales.
- Corregir contenidos.
- Adaptar textos.
- Configurar permisos.
- Publicar recursos.
- Organizar repositorios.

Estas acciones permiten obtener evidencias más próximas a la práctica docente real.

## Relación con el MRCDD

Las pruebas se diseñan a partir de los indicadores de logro del Área 2 del MRCDD.

Cada prueba no evalúa un único indicador aislado, sino una combinación integrada de indicadores vinculados a una competencia y nivel concretos.

## Enfoque formativo

Aunque la aplicación genera una valoración automática, la evaluación también tiene una finalidad formativa. Por ello, las pruebas deben incluir retroalimentación que ayude al usuario a comprender:

- Qué criterios ha cumplido.
- Qué errores ha cometido.
- Cómo podría mejorar su respuesta.
