# Competencia 2.3: Protección, gestión y compartición de contenidos digitales

Esta competencia evalúa la gestión responsable de contenidos digitales: licencias, permisos, metadatos, organización, publicación y reutilización.

| Nivel | Prueba | Tipo de tarea | Evidencia evaluada |
|---|---|---|---|
| A1 | P09 | Clasificación de archivos y licencias | Organización básica según permisos de reutilización. |
| A2 | P10 | Configuración de permisos | Asignación de accesos según perfiles educativos. |
| B1 | P11 | Publicación de recurso | Metadatos, etiquetas y licencia de publicación. |
| B2 | P12 | Optimización de repositorio | Reorganización avanzada para mejorar reutilización. |
