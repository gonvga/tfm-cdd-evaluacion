# Resumen general de pruebas

La aplicación organiza la evaluación en 12 pruebas. Cada prueba evalúa una combinación concreta de competencia y nivel.

| ID | Competencia | Nivel | Nombre | Evidencia principal |
|---|---|---|---|---|
| P01 | 2.1 | A1 | Detectar recursos adecuados | IDs seleccionados, timestamp y score. |
| P02 | 2.1 | A2 | Seleccionar el mejor recurso | Recurso seleccionado y tiempo empleado. |
| P03 | 2.1 | B1 | Organizar un banco de recursos | Mapa final de carpetas. |
| P04 | 2.1 | B2 | Curación avanzada de contenidos | Tabla de puntuaciones y selección final. |
| P05 | 2.2 | A1 | Corregir una ficha educativa | Texto final editado. |
| P06 | 2.2 | A2 | Completar plantilla didáctica | JSON con campos completados. |
| P07 | 2.2 | B1 | Adaptar recurso para accesibilidad | Versión adaptada del texto. |
| P08 | 2.2 | B2 | Diseñar secuencia digital | Orden final y licencia seleccionada. |
| P09 | 2.3 | A1 | Clasificar archivos y licencias | Estructura final de carpetas. |
| P10 | 2.3 | A2 | Configurar permisos | Tabla final de permisos. |
| P11 | 2.3 | B1 | Publicar recurso correctamente | Metadatos publicados. |
| P12 | 2.3 | B2 | Optimizar repositorio digital | Estado inicial y final del repositorio. |
