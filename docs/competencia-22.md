# Competencia 2.2: Creacion y modificacion de contenidos digitales

La competencia 2.2 del MRCDD se evalua mediante cuatro pruebas progresivas: P05, P06, P07 y P08. Todas estan planteadas como tareas practicas de revision, adaptacion, autoria y empaquetado de contenidos digitales educativos.

## Vision General

| Prueba | Nivel | Foco de evaluacion | Archivo de datos | Vista |
|---|---|---|---|---|
| P05 | A1 | Revision basica de licencia, cita, accesibilidad, adecuacion didactica y herramientas de autor | `data/p05_comp22_a1.json` | `ui/test_views/comp22/p05_corregir_ficha.py` |
| P06 | A2 | Configuracion guiada de una plantilla didactica accesible y compatible con el centro | `data/p06_comp22_a2.json` | `ui/test_views/comp22/p06_completar_plantilla.py` |
| P07 | B1 | Modificacion practica de un recurso abierto para crear una ficha adaptada | `data/p07_comp22_b1.json` | `ui/test_views/comp22/p07_adaptar_recurso.py` |
| P08 | B2 | Diseno, integracion, modificacion, seguridad colaborativa y empaquetado de una secuencia digital | `data/p08_comp22_b2.json` | `ui/test_views/comp22/p08_disenar_secuencia.py` |

## P05 - Nivel A1

P05 evalua el acceso inicial a la creacion y modificacion de contenidos. El usuario revisa una ficha digital antes de publicarla en el aula virtual.

**Indicadores evaluados**

- `2.2.A1.1`: conocimiento basico de licencias, autoria y referencias.
- `2.2.A1.2`: aplicacion inicial de criterios de accesibilidad y adecuacion didactica.
- `2.2.A1.3`: identificacion de herramientas de autor apropiadas para modificaciones sencillas.

**Tareas**

| Fase | Accion del usuario | Evidencia generada |
|---|---|---|
| Licencia y referencia | Seleccionar licencias reutilizables y una referencia APA basica | Licencia y cita elegidas |
| Accesibilidad | Marcar acciones accesibles y elegir texto alternativo | Medidas seleccionadas |
| Adecuacion didactica | Escoger la version textual mas adecuada para 2 ESO | Texto adaptado seleccionado |
| Herramientas de autor | Asociar cada modificacion con la herramienta correcta | Herramientas asignadas |

Para superar P05, el usuario debe elegir licencias que permitan adaptar, citar correctamente, aplicar mejoras de accesibilidad, mantener rigor en la redaccion y escoger herramientas adecuadas.

## P06 - Nivel A2

P06 evalua la aplicacion guiada de criterios didacticos, disciplinares, tecnicos y de accesibilidad mediante la edicion de un recurso en una herramienta de autor simulada.

**Indicadores evaluados**

- `2.2.A2.1`: adaptacion de contenidos digitales con apoyo y segun un contexto concreto.
- `2.2.A2.2`: uso de un sistema de referencias integrado en la herramienta de autor.
- `2.2.A2.3`: uso tutelado de herramientas institucionales y formatos compatibles.

**Tareas**

| Fase | Accion del usuario | Evidencia generada |
|---|---|---|
| Edicion | Reescribir titulo y explicacion para 1 ESO conservando el rigor | Texto adaptado |
| Accesibilidad | Redactar el texto alternativo y aplicar ajustes de estructura y percepcion | Configuracion accesible |
| Herramienta institucional | Configurar eXeLearning, la estructura y la navegacion | Plantilla configurada |
| Referencias | Revisar y corregir metadatos importados mediante la funcion Referencias | Referencia configurada |
| Publicacion | Elegir una salida compatible con el Moodle del centro | Formato de exportacion |

Para superar P06, el usuario debe producir una adaptacion valida, aplicar los ajustes indicados en el manual, corregir la atribucion importada del material original y preparar una salida compatible con Moodle.

## P07 - Nivel B1

P07 evalua la autonomia para modificar un recurso digital abierto y convertirlo en una obra derivada adecuada para un grupo concreto.

**Indicadores evaluados**

- `2.2.B1.1`: modificacion autonoma de contenidos digitales existentes.
- `2.2.B1.2`: adaptacion didactica y accesible mediante herramientas de autor.
- `2.2.B1.3`: respeto de licencias, atribucion y metadatos en una obra derivada.

**Tareas**

| Fase | Accion del usuario | Evidencia generada |
|---|---|---|
| Constructor de ficha | Anadir, quitar y ordenar bloques de contenido | Secuencia de bloques |
| Accesibilidad | Integrar esquema accesible, etiquetas y glosario visual | Bloques accesibles incluidos |
| Licencia | Elegir licencia compatible con la obra original CC BY-SA | Licencia seleccionada |
| Metadatos | Completar nivel, materia, accesibilidad y atribucion | Metadatos guardados |

P07 utiliza recursos visuales ubicados en:

```text
assets/p07/
```

Para superar P07, el usuario debe crear una ficha derivada ordenada, accesible, adecuada a 1 ESO, con licencia CC BY-SA compatible y metadatos completos.

## P08 - Nivel B2

P08 evalua un desempeño avanzado: el usuario disena una secuencia digital completa, integra recursos de distintas fuentes, aplica modificaciones, incorpora elementos propios y prepara un paquete exportable.

**Indicadores evaluados**

- `2.2.B2.1`: integracion de contenidos digitales en una secuencia coherente.
- `2.2.B2.2`: modificacion y adaptacion de recursos para necesidades concretas.
- `2.2.B2.3`: creacion de elementos propios dentro de una propuesta digital.
- `2.2.B2.4`: empaquetado y despliegue en formatos compatibles con el aula virtual.

**Tareas**

| Fase | Accion del usuario | Evidencia generada |
|---|---|---|
| Banco de contenidos | Seleccionar y ordenar recursos externos y propios | Secuencia de recursos |
| Modificaciones | Marcar adaptaciones didacticas, accesibles y de atribucion | Modificaciones aplicadas |
| Seguridad colaborativa | Activar historial, copia de seguridad y permisos docentes | Medidas de seguridad |
| Evaluacion previa | Seleccionar criterios de revision sistematica | Matriz de evaluacion |
| Exportacion | Configurar formato, metadatos, comprobacion y despliegue | Paquete preparado |

P08 utiliza recursos visuales ubicados en:

```text
assets/p08/
```

Para superar P08, el usuario debe construir una secuencia coherente, incluir recursos propios, modificar contenidos externos cuando sea necesario, proteger la edicion colaborativa y exportar en un formato compatible como SCORM 1.2.

## Feedback E Interfaz

Las pruebas P05-P08 ofrecen feedback contextual sobre licencia, accesibilidad, adecuacion didactica, autoria, metadatos y compatibilidad tecnica. En los niveles B1 y B2, la interfaz simula procesos de construccion de productos digitales para recoger evidencias mas cercanas al desempeño real.

## Progresion A1-B2

| Nivel | Desempeño principal |
|---|---|
| A1 | Revisa licencias, citas, accesibilidad y herramientas basicas |
| A2 | Configura una plantilla con apoyo y criterios institucionales |
| B1 | Modifica un recurso abierto y crea una ficha adaptada |
| B2 | Disena, protege, evalua y empaqueta una secuencia digital |

Esta progresion permite pasar de la revision inicial de recursos a la creacion de secuencias digitales completas, accesibles, reutilizables y desplegables en plataformas educativas.
