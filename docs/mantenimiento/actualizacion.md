# Actualización de contenidos

La aplicación está pensada para poder actualizarse de forma progresiva.

## Qué se puede actualizar

- Textos de los escenarios.
- Recursos utilizados en las pruebas.
- Opciones de respuesta.
- Criterios de evaluación.
- Feedback formativo.
- Nuevas pruebas o variantes.
- Documentación web.

## Recomendaciones

- Mantener los IDs de pruebas estables.
- Documentar todos los cambios relevantes.
- Revisar las pruebas unitarias después de cada modificación.
- Validar manualmente la prueba en la interfaz.
- Evitar cambios simultáneos en muchas pruebas.
- Mantener una correspondencia clara entre JSON, vista y documentación.
