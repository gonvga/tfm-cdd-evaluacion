# Requisitos

## Requisitos técnicos

Para ejecutar la aplicación se necesita:

- Python 3.10 o superior.
- Entorno virtual recomendado.
- Dependencias instaladas desde `requirements.txt`.
- Sistema operativo compatible con Python y Flet: Windows, macOS o Linux.

## Dependencias principales

La aplicación utiliza principalmente:

- **Flet**, para construir la interfaz gráfica.
- **JSON**, para definir escenarios y almacenar resultados.
- **pytest**, para validar la lógica mediante pruebas unitarias.
- Librerías estándar de Python para gestión de archivos, fechas y estructuras de datos.

## Estructura mínima esperada

El repositorio debe conservar una estructura similar a esta:

```text
TFM-FORM-PROF-2025-26/
├─ app.py
├─ core/
├─ data/
├─ docs/
├─ results/
├─ ui/
├─ unit_tests/
├─ requirements.txt
└─ mkdocs.yml
```
