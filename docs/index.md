# Evaluación de la competencia digital docente

Esta aplicación evalúa el Área 2 del Marco de Referencia de la Competencia Digital Docente mediante tareas prácticas.

## Competencias evaluadas

| Competencia | Descripción |
|---|---|
| 2.1 | Búsqueda y selección de contenidos digitales |
| 2.2 | Creación y modificación de contenidos digitales |
| 2.3 | Protección, gestión y compartición de contenidos digitales |

## Pruebas

| Competencia | A1 | A2 | B1 | B2 |
|---|---|---|---|---|
| 2.1 | P01 | P02 | P03 | P04 |
| 2.2 | P05 | P06 | P07 | P08 |
| 2.3 | P09 | P10 | P11 | P12 |

El usuario avanza de forma progresiva:

```
A1 → A2 → B1 → B2
```

## Pruebas A2 actualizadas

Las pruebas A2 evalúan la aplicación práctica con ayuda:

- **P02:** define requisitos, elige estrategias de búsqueda y compara al menos tres recursos.
- **P06:** adapta un contenido, mejora su accesibilidad, configura una herramienta de autor y corrige una referencia.
- **P10:** publica un paquete SCORM, configura permisos y completa la catalogación institucional.

Después de validar, cada prueba muestra feedback sobre los aciertos y errores.

## Uso rápido

La forma más sencilla de usar la aplicación es la versión portable de Windows:

1. Descomprime `EvaluacionCDD-portable-windows.zip`.
2. Abre la carpeta `EvaluacionCDD-portable`.
3. Ejecuta `EvaluacionCDD-portable.exe`.

El ejecutable debe permanecer junto a la carpeta `_internal`.

Los resultados se guardan automáticamente en la carpeta `results`.
